# Liberty Stack Deployment

Upload every file in this folder to the root of your GitHub repository.

Required files:

- `index.html`
- `plans.html`
- `services.html`
- `work.html`
- `contact.html`
- `404.html`
- `styles.css`
- `style.css`
- `script.js`
- `site.js`
- `CNAME`
- `.nojekyll`
- `robots.txt`
- `sitemap.xml`

GitHub Pages settings:

1. Open the repository settings.
2. Go to Pages.
3. Set Source to `Deploy from a branch`.
4. Select the `main` branch.
5. Select the `/ (root)` folder.
6. Save.
7. In Custom domain, enter `libertystack.co.in`.

If the site still shows "There isn't a GitHub Pages site here", the files are probably not the issue. That message usually means GitHub Pages is not enabled, the deployment failed, or the custom domain is not connected to the repository.
